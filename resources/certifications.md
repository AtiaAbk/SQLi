# 🏅 Certification Roadmap

| Certification | When to Pursue | Focus |
|---|---|---|
| **CompTIA Security+** | Right after finishing this repo's Beginner–Intermediate phases | Broad security fundamentals; great general-purpose entry point, often a job-posting checkbox |
| **eJPT (eLearnSecurity Junior Penetration Tester)** | After completing Phases 1–5 (fundamentals + secure coding) | Practical, beginner-friendly, hands-on pentesting fundamentals including web app testing |
| **CompTIA CySA+** | If leaning toward blue-team/detection work | Aligns well with this repo's Detection & Monitoring phase (Phase 7) |
| **PNPT (Practical Network Penetration Tester)** | After eJPT, once comfortable with a full attack methodology in authorized environments | Realistic, scenario-based practical exam |
| **OSCP (Offensive Security Certified Professional)** | Future/long-term goal, after solid hands-on experience across many authorized labs | Industry-respected, rigorous, fully practical exam — a natural "next chapter" beyond this repository |

## Suggested Order for a Defensive/AppSec-Leaning Path
1. Security+ → foundational vocabulary and concepts
2. This repository (full roadmap) → deep SQLi + secure coding understanding
3. eJPT → validate hands-on fundamentals
4. CySA+ (if pursuing blue team/detection) **or** PNPT (if pursuing offensive/red team)
5. OSCP → long-term milestone once ready for a fully practical, rigorous exam

> Certifications are a supplement to hands-on skill, not a replacement for it. The labs and secure-coding exercises in this repository directly build the skills these exams test.
