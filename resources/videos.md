# 🎥 Video Resources

## Conference Talks
- **DEF CON / Black Hat talks on injection & AppSec** — search the official DEF CON Media Server (defcon.org/html/links/dc-media-archives.html) and Black Hat's YouTube channel for current SQLi/AppSec talks
- **OWASP Global AppSec conference talks** — OWASP's YouTube channel publishes full conference recordings, many directly on injection prevention

## YouTube Channels
- **OWASP Foundation** — official channel with conference talks and project overviews
- **PortSwigger** — short, high-quality explainer videos accompanying their Web Security Academy labs
- **Computerphile** — strong general CS explainers, including accessible episodes on how SQL injection works conceptually
- **NetworkChuck / John Hammond** *(use judgment)* — general security education channels; prioritize episodes framed around authorized labs (TryHackMe, HTB) and defensive explanations

## University Courses
- **MIT OpenCourseWare** — search for "Computer Systems Security" (6.858) which includes web security modules covering injection classes
- **Stanford CS 253: Web Security** — publicly available lecture materials covering injection and web app security fundamentals

## Playlists
- PortSwigger's official "SQL injection" topic playlist on their Web Security Academy site (video + lab pairing)
- OWASP DevSlop / OWASP project demo playlists on the OWASP YouTube channel

> Search each platform directly for the most current uploads — video content and links change more frequently than documentation.
