# ⭐ Recommended GitHub Repositories

## Practice Platforms
| Repository | Why It's Valuable |
|---|---|
| [OWASP/juice-shop](https://github.com/juice-shop/juice-shop) | The most feature-complete modern vulnerable web app; actively maintained, gamified scoring, covers the full OWASP Top 10 |
| [digininja/DVWA](https://github.com/digininja/DVWA) | Classic adjustable-difficulty app; excellent for comparing vulnerable vs. secure ("impossible") source code side by side |
| [WebGoat/WebGoat](https://github.com/WebGoat/WebGoat) | Lesson-driven, explanation-first — ideal for true beginners |
| [webpwnized/mutillidae](https://github.com/webpwnized/mutillidae) | Broad coverage, popular in classroom settings |
| [Audi-1/sqli-labs](https://github.com/Audi-1/sqli-labs) | Deep, SQLi-specific progression across many query contexts |

## OWASP Official Resources
| Repository | Why It's Valuable |
|---|---|
| [OWASP/CheatSheetSeries](https://github.com/OWASP/CheatSheetSeries) | The canonical, community-vetted SQL Injection Prevention Cheat Sheet and dozens of related guides |
| [OWASP/www-project-web-security-testing-guide](https://github.com/OWASP/www-project-web-security-testing-guide) | Structured methodology for authorized security testing |
| [OWASP/ASVS](https://github.com/OWASP/ASVS) | Application Security Verification Standard — great as a requirements checklist for secure data access |

## Awesome Lists
| Repository | Why It's Valuable |
|---|---|
| [sbilly/awesome-security](https://github.com/sbilly/awesome-security) | Broad curated list spanning many security domains, useful for going beyond SQLi |
| [PaulSec/awesome-sec-talks](https://github.com/PaulSec/awesome-sec-talks) | Curated list of conference talks, including many on injection and AppSec |

## Detection & Secure Coding Tooling
| Repository | Why It's Valuable |
|---|---|
| [returntocorp/semgrep](https://github.com/semgrep/semgrep) | Fast, open-source static analysis; great for writing custom rules to flag dynamic SQL construction in CI |
| [OWASP/owasp-mstg](https://github.com/OWASP/owasp-mstg) *(if extending into mobile)* | Mobile-specific testing guide, includes local-storage/SQLite-relevant guidance |

> Always check a repository's activity, license, and issue tracker before relying on it — the security tooling space moves quickly.
