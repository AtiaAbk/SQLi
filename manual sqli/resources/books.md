# 📚 Recommended Books

| Title | Author | Difficulty | Topics | Why Read It |
|---|---|---|---|---|
| *The Web Application Hacker's Handbook* | Dafydd Stuttard & Marcus Pinto | 🟡 Intermediate | Full web AppSec, including injection classes | The definitive, thorough reference for how web vulnerabilities work and how to test for them responsibly |
| *SQL Injection Attacks and Defense* | Justin Clarke-Salt (ed.) | 🔴 Advanced | SQLi specifically, across many databases | The most focused single text on SQLi theory and defense across engines |
| *Secure by Design* | Dan Bergh Johnsson, Daniel Deogun, Daniel Sawano | 🟡 Intermediate | Secure software design patterns | Teaches how to design data layers so entire vulnerability classes become structurally impossible |
| *Database Security* | Alfred Basta, Melissa Zgola | 🟢 Beginner–Intermediate | DB security fundamentals | Good foundational text on database-level hardening and access control |
| *Threat Modeling: Designing for Security* | Adam Shostack | 🟡 Intermediate | Threat modeling methodology | Essential for the "Code Review & Threat Modeling" phase of the roadmap |
| *Tangled Web: A Guide to Securing Modern Web Applications* | Michal Zalewski | 🔴 Advanced | Browser/web security fundamentals | Deepens understanding of the broader web security context injection lives in |
